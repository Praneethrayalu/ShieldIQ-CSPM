    FAQ

    Questions,
    answered

    01What does ShieldIQ actually do?

    It reads the settings of your cloud accounts and tools, looks for risky ones (like a database anyone on the internet can reach), links them into the paths an attacker could follow, and gives you the fix for each.

    02Will it change anything in my cloud?

    No. Live connections are read-only. One-click auto-fix changes ShieldIQ's stored copy of a demo or imported configuration and re-scans to prove the fix. For a live account you get the exact command or Terraform to apply yourself, or a GitHub pull request.

    03Which platforms can I connect?

    AWS and GitHub connect live with read-only access. Google Cloud, Azure and Slack are scanned from a JSON snapshot you export, and Kubernetes from YAML. The guides above show each one click by click.

    04Is this a real company?

    No. ShieldIQ is a student portfolio project built to learn and demonstrate cloud security engineering. No company uses it, and the demo workspace “Acme Labs” is fictional.

    05Do I need to pay for anything?

    No. It runs on your own machine with built-in sample data, so you can try every feature without accounts or API keys.
