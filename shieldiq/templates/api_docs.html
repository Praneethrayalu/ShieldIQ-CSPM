Automate ShieldIQ from CI/CD. Create a token in Settings; requests are scoped to your organization and role.

Quick start

export SHIELDIQ_TOKEN=siq_...
curl -H "Authorization: Bearer $SHIELDIQ_TOKEN" {{ base }}/summary

  {{ base }}/scan/iac
